1. Giriş

Bu rapor, Web Tabanlı Programlama dersi kapsamında geliştirilen "Web Bileşen Kütüphanesi" projesini kapsamlı biçimde açıklamaktadır. Proje; modern web standartlarını, framework bağımsız mimarisini ve yeniden kullanılabilir bileşen yaklaşımını benimseyerek Vanilla JavaScript, Shadow DOM ve Custom Elements API üzerine inşa edilmiş bir Web Components UI kütüphanesidir.

Günümüz web geliştirme ekosisteminde React, Vue ve Angular gibi büyük frameworkler yaygın olarak kullanılmaktadır. Ancak bu frameworklerin her projede zorunlu bağımlılıklara yol açtığı görülebilmektedir. Bu proje, tarayıcı tarafından doğrudan desteklenen Web Components standardını kullanarak herhangi bir framework bağımlılığı olmaksızın güçlü ve esnek bir UI kütüphanesi oluşturmayı hedeflemiştir.

2. Proje Tanımı ve Amacı

"Web Bileşen Kütüphanesi", 20 adet yeniden kullanılabilir Web Component barındıran, tamamen Vanilla JavaScript ile yazılmış bir UI kütüphanesidir. Projenin temel amaçları şunlardır:

  • Framework bağımsız, herhangi bir HTML sayfasında kullanılabilir bileşen seti oluşturmak
  • Shadow DOM ile stil kapsülleme (encapsulation) sağlamak
  • CSS Custom Properties ile dinamik tema desteği sunmak
  • WCAG 2.1 standartlarına uygun erişilebilir bileşen yazmak
  • ES Modules ile modüler ve sürdürülebilir kod mimarisi kurmak
  • Kapsamlı bir demo sayfası ile kullanım kolaylığı sağlamak

6. Web Components API Kullanımları

Bu projede Web Components standardının 3 temel yapı taşı eksiksiz kullanılmıştır:

6.1 Custom Elements API

customElements.define('wc-*', SinifAdi) çağrısıyla her bileşen tarayıcıya tanıtılmıştır. Her bileşen kendi dosyasında tanımlanmakta, src/index.js aracılığıyla tek noktadan dışa aktarılmaktadır.

class WcModal extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' }); // Shadow DOM eklendi
  }
  static get observedAttributes() { return ['open', 'title']; }
  connectedCallback() {
    this.setAttribute('role', 'dialog');
    this.setAttribute('aria-modal', 'true');
    this.render();
  }
  attributeChangedCallback(name, oldVal, newVal) {
    if (oldVal !== newVal) this.render(); // Reaktif güncelleme
  }
}
customElements.define('wc-modal', WcModal);

6.2 Shadow DOM

attachShadow({ mode: 'open' }) ile CSS kapsülleme sağlanmıştır. Bileşen stilleri dışarıya sızmaz; dışarıdaki stiller bileşeni bozmaz. CSS Custom Properties ise bu izolasyonu aşarak esnek tema desteği sağlar.

6.3 HTML Templates API

<wc-card> bileşeninde document.createElement('template') kullanılmıştır. DOM bir kez parse edilir, her kullanımda .cloneNode(true) ile kopyalanarak yüksek performans elde edilir.

6.4 Tema Sistemi

7. Erişilebilirlik (A11y)

Erişilebilirlik bu kütüphanenin öncelikli odak noktalarından biridir. WCAG 2.1 standartları referans alınmıştır.

7.1 Focus Trap (Klavye Tuzağı)

<wc-modal> açıldığında Tab tuşuyla gezinme yalnızca modal içinde kalır. Bu özellik WCAG 2.1.2 gereksinimini karşılar.

_trapFocus(e) {
  if (e.key !== 'Tab') return;
  const focusable = [...this.shadowRoot.querySelectorAll(
    'button, [href], input, [tabindex]:not([tabindex="-1"])'
  )];
  const slotted = [...this.querySelectorAll(
    'button, [href], input, [tabindex]:not([tabindex="-1"])'
  )];
  const all = [...focusable, ...slotted].filter(el => !el.disabled);
  const first = all[0];
  const last  = all[all.length - 1];
  if (e.shiftKey && document.activeElement === first) {
    e.preventDefault(); last.focus();
  } else if (!e.shiftKey && document.activeElement === last) {
    e.preventDefault(); first.focus();
  }
}

7.2 Klavye Navigasyonu

  • wc-tabs: Yön tuşları, Home ve End ile sekme değiştirme
  • wc-dropdown: Enter, Boşluk ve yön tuşlarıyla kontrol
  • wc-modal: ESC tuşu ile kapatma

7.3 ARIA Etiketleri

role="dialog", aria-modal, aria-selected, aria-expanded gibi etiketler state değişimlerinde dinamik olarak güncellenmektedir.

8. Zorluklar ve Çözümler

Zorluk 1 — Shadow DOM Tema Yönetimi

Problem: Shadow DOM içindeki elementlerin dışarıdan tamamen izole olması nedeniyle renk/font gibi tema bilgilerinin bileşene aktarılamaması.

Çözüm: CSS Custom Properties (--wc-*) kullanıldı. Shadow DOM bu değişkenlerin dışarıdan içeriye sızmasına izin verir; böylece izolasyon bozulmadan tema desteği sağlandı.

Zorluk 2 — Dışarıya Tıklanınca Kapanma

Problem: Dropdown ve Modal'ın "dışarıya tıklanınca kapanma" davranışında event target'ın Shadow Root nedeniyle her zaman host element olarak görünmesi.

Çözüm: Event listener'lar document düzeyine bağlandı. .contains(e.target) ile tıklamanın host içinde mi dışında mı olduğu kontrol edildi.

Zorluk 3 — Modal A11y Focus Trap

Problem: Modal açıkken arka plandaki içeriğe Tab tuşuyla erişilebilmesi (WCAG 2.1.2 ihlali).

Çözüm: Özel _trapFocus() metodu yazıldı. Shift+Tab ve Tab yönleri kontrol edilerek odak döngüsü oluşturuldu.

Zorluk 4 — ES Module CORS Kısıtlaması

Problem: ES Modules'un CORS kısıtlaması nedeniyle dosya sistemi üzerinden doğrudan (file:// protokolüyle) açılamaması.

Çözüm: VS Code Live Server uzantısı veya herhangi bir HTTP sunucusu kullanılması gerektiği dokümante edildi.

9. Sonuç

Bu proje kapsamında geliştirilen "Web Bileşen Kütüphanesi", modern tarayıcı standartları kullanılarak oluşturulmuş, 20 adet Web Component barındıran kapsamlı bir UI kütüphanesidir. Projenin en önemli kazanımları şu şekilde özetlenebilir:

  • Web Components'in 3 temel yapı taşı (Custom Elements, Shadow DOM, HTML Templates) başarıyla uygulanmıştır
  • Herhangi bir framework bağımlılığı olmadan çalışabilmektedir
  • CSS Custom Properties tabanlı esnek tema sistemi oluşturulmuştur
  • WCAG 2.1 standartlarına uygun erişilebilirlik özellikleri eklenmiştir
  • Kapsamlı demo sayfası ile kullanıcılara canlı ön izleme imkânı sunulmuştur
  • GitHub üzerinde versiyon kontrolü sağlanmıştır

Proje, gerçek dünyada kullanılabilecek kalitede, production-ready bir UI kütüphanesi olma hedefine ulaşarak tamamlanmıştır.
