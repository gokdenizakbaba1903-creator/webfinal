🚀 Hızlı Başlangıç 📦 Kurulum 🎨 Özelleştirme

Kütüphaneyi kullanmaya başlamak için tek yapmanız gereken JS dosyalarını import etmektir:

<script type="module" src="./src/index.js"></script>

<wc-button theme="primary">Merhaba Dünya!</wc-button>

Bileşenleri tek tek veya toplu olarak import edebilirsiniz:

import { WcButton, WcCard, WcModal } from './src/index.js';

// Veya tek tek:
import WcButton from './src/components/wc-button/wc-button.js';

CSS custom properties ve part selector ile özelleştirebilirsiniz:

wc-button::part(button) {
  border-radius: 999px; /* Pill şekli */
}

wc-card::part(card) {
  border: 2px solid #6366f1;
}
